3. **Product Lineup (주요 제품군 4대 탭 뷰)**

   - **Tab 4: 특수 사이니지**: 외벽 투명 LED(70%+ 투과율), 포스터 LED, 스토어 쉘프, 코너 곡면 아나모픽 3D 파사드

   - 음향 및 흡음 인테리어 연계 3단계 투자 변동 요인 (Tier 1~3)
   - **실시간 B2B 맞춤 견적 계산기 시뮬레이터**: 공간/등급/옵션 선택 시 예상 예산 및 추천 사양 즉시 산출 & 견적 폼 자동 연동

   - 서울대학교병원, 빗썸 삼성라운지, 셀트리온 스마트케이타워, 한국전기연구원(KERI), CJ 올리브영 명동 매장, 사천시 의회 본회의장
